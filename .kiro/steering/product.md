# Product Overview

UTASVotes is a secure digital electoral system for the University of Technical and Applied Sciences (UTAS) in Ghana. The platform enables students to participate in departmental and university-wide elections remotely, eliminating physical barriers and promoting transparency.

## Core Purpose

Replace traditional in-person voting with a modern, accessible web application that maintains election integrity while improving student participation and engagement.

## Key User Roles

- **Students**: Vote in elections, view candidate manifestos, engage with campaign content
- **Candidates/Aspirants**: Apply for positions, pay application fees (Ghana Cedis), upload profiles/manifestos, share campaign updates
- **Electoral Commission (EC)**: Manage elections, verify candidates, import voter data, monitor real-time results, generate certified reports
- **Administrators**: Oversee system operations, update fee structures, ensure platform integrity

## Critical Features

- Exclusive access via institutional emails (@cktutas.edu.gh)
- Multi-level voting (departmental → university-wide)
- Real-time election dashboards and analytics
- Integrated payment gateway (Stripe) for application fees
- Candidate onboarding with verification workflow
- Campaign feed with interactive engagement features
- One-click certified result generation with automated email distribution
