## Design Elements

### Color Scheme
- **Header Gradient**: #F2B807 → #D97904 (Yellow to Orange)
- **Primary Button**: Same gradient with shadow
- **Info Boxes**: Light yellow background (#FFF9E6)
- **Security Boxes**: Light red background (#FFF0F0)
- **Text**: Dark gray (#1a1a1a) for headings, medium gray (#4a4a4a) for body

### Typography
- **Headings**: 24-32px, Bold (700)
- **Body Text**: 14-16px, Regular (400)
- **Small Text**: 12-13px for footer

### Spacing
- **Padding**: 30-40px for sections
- **Margins**: 20-30px between elements
- **Button**: 16px vertical, 40px horizontal padding

### Responsive Design
- **Max Width**: 600px for email container
- **Mobile**: Stacks vertically, maintains readability
- **Buttons**: Large enough for touch (44px+ height)

## Key Features

1. **Professional Branding**
   - UTASVotes logo/name prominent
   - University name clearly displayed
   - Consistent color scheme

2. **Clear Call-to-Action**
   - Large, prominent buttons
   - Alternative text link provided
   - Action-oriented language

3. **Security Information**
   - Expiration times clearly stated
   - Security tips included
   - Warning about suspicious emails

4. **User Guidance**
   - What to expect next
   - How to use the link
   - What features are available

5. **Mobile-Friendly**
   - Responsive design
   - Large touch targets
   - Readable on small screens
